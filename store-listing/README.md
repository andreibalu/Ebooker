# Localized App Store listing drafts

These drafts are for the **next** App Store version. 1.4.1 is live with only the en-US localization; 1.5.0 is next; these locales have not been uploaded yet. When the next version opens, review the translations and current subscription terms, then copy each locale's subtitle to its app info localization and its promotional text, keywords, and description to its version localization. App Store Connect remains the source of truth for availability and localized prices.

Once a version ships, delete or refresh any draft here that it used, so this folder never describes a submitted version.
